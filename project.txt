# JOBTRACK — PERSONAL JOB APPLICATION TRACKER + JOB SHARING PLATFORM

Build a complete web application called **JobTrack**.

JobTrack is a personal job application tracker combined with a simple job-sharing system for friends.

The application allows users to:

* Save job opportunities
* Track applications
* Track exactly which resume was used
* Manage multiple resume versions
* Track assessments and interviews
* Track follow-ups
* Add and manage walk-in drives
* Receive walk-in reminders
* Send reminders to multiple email addresses
* Share job links with Everyone, Friends, or Only Me
* See jobs shared by other users
* See friends' shared job links
* Filter jobs by friend, company, role, location, source, etc.
* Save a friend's job into their own private job tracker
* Open the original job link and apply
* Share walk-in drives
* Save shared walk-ins into their own private walk-in list

The application should be simple, clean, fast, mobile responsive, and easy to maintain.

---

# 1. VERY IMPORTANT ARCHITECTURE RULES

This is NOT a public job portal.

It is a personal job tracking application with optional job sharing.

DO NOT use:

* n8n
* FastAPI
* Express
* Docker
* Kubernetes
* Microservices
* AI APIs
* LLM APIs

Keep the architecture simple.

# 49. SHARING LOGIC

If job.visibility = private:

Only owner can see it.

If job.visibility = everyone:

Any authenticated JobTrack user can see it.

If job.visibility = friends:

Only accepted friends can see it.

The same logic applies to walk-ins.

Private application data must NEVER leak through the shared job feed.

A user viewing a shared job must only receive the public/shared fields.

Do not expose private application fields through API responses.
